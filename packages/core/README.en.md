# @ygy-code/core

[简体中文](./README.md) · [English](./README.en.md)

Core AI engine powering [ygy-code](https://github.com/GGGuYu/ygy-code).

This package is the headless runtime consumed by `@ygy-code/cli` — agent loop, tools, provider registry, and permission system. It has **no UI dependencies** and can in principle be embedded in other tools.

> ⚠️ The public API is not yet stable — breaking changes may happen between minor versions. If you just want the CLI, install [`@ygy-code/cli`](https://www.npmjs.com/package/@ygy-code/cli) directly.

For full installation, ChatGPT sign-in, API key setup, and usage, see the [main repo README](https://github.com/GGGuYu/ygy-code).
